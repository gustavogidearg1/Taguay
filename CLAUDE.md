# Repositorio de Taguay — sistema.taguay.com.ar

Proyecto Laravel (PHP + Composer). Front con Vite + Tailwind CSS.

## Idioma
- Escribir todos los comentarios de código en español.
- Generar todos los archivos, textos y documentación en español.
- Responder en español.

## Estilos y UI
- Tomar como referencia de estilo los lineamientos visuales de Angular Material
  (jerarquía, espaciados, elevación, componentes).
- Color principal: `#198754`
- Color secundario: `#0d6efd`
- Usar estos colores de forma consistente en botones, enlaces y acentos.

## Convenciones generales
- Mantener la nomenclatura y la estructura de carpetas existente del proyecto.
- No ejecutar `git commit` ni `git push` salvo pedido explícito.
- Preguntar antes de instalar dependencias nuevas (Composer o npm).
- No modificar archivos generados ni `vendor/`, `node_modules/`.

## Comandos útiles
- Servir en local: `php artisan serve`
- Migraciones: `php artisan migrate`
- Compilar assets (dev): `npm run dev`
- Compilar assets (prod): `npm run build`
- Tests: `php artisan test`
