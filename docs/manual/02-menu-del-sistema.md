# Menú del sistema

El menú superior muestra solo las opciones a las que cada usuario tiene acceso. Si un menú no aparece, falta el rol correspondiente (ver *01 - Usuarios, roles y reportes*).

## Cargar Avance

Botón verde destacado. Abre el formulario **Cargar Avance de Campo**: la carga de estados de lotes (siembra, madurez, cosecha…), pensada para usar desde el celular en el campo.

- **Quién lo ve:** rol Agrícola y Administrador.
- El combo **Estado** viene preseleccionado con el estado marcado como *por defecto* en *ABM → Agrícola → Estados de Cultivo*.

## ABM (solo Administrador)

El menú **ABM** reúne las tablas de configuración del sistema ("Altas, Bajas y Modificaciones"). Está organizado en secciones que se despliegan al tocarlas.

### ABM → Agrícola

| Opción | Para qué sirve |
|---|---|
| Establecimiento | Campos o establecimientos de la empresa |
| Cultivo | Tipos de cultivo (soja, maíz, trigo, etc.) |
| Campañas | Campañas agrícolas (por ejemplo 26/27) |
| Lotes | Lotes de cada establecimiento |
| Estados de Cultivo | Estados que se eligen al cargar un avance (Siembra, Madurez, Cosecha…). Aquí se marca cuál viene **por defecto**. |
| Rindes | Registro de rindes |

### Importación de facturas

Disponible solo para el **Administrador**. Para usarla hay que haber iniciado sesión.
